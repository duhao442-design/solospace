# aMoneySystem - 复式记账桌面应用

一个基于 Electron + Vue3 + Element Plus 开发的个人/家庭复式记账桌面应用。

## 功能特性

### 1. 首页概览
- 展示总收入、总支出、净资产统计卡片
- 最近交易记录列表
- 消费倾向扇形分析图（支持7天/30天/90天/自定义日期范围）

### 2. 全部账单
- 查看所有账单记录
- 按日期范围、收支类型筛选
- 分页浏览
- 删除账单功能

### 3. 每月收支分析
- 月度收入、支出、结余统计
- 多维度扇形图分析（消费分类、消费必要性等）
- 详细数据列表及占比展示

### 4. 家庭管理
- 创建/编辑/删除家庭
- 管理家庭成员
- 支持多家庭切换

### 5. 新增账单
- 收入/支出类型选择
- 金额、日期、记账人录入
- 家庭支出标记
- 多维度标签选择（支持二级分类）
- 备注信息

### 6. 系统管理
- 标签类型管理（支持二级分类配置）
- 标签值维护
- 数据导出备份
- 数据导入恢复
- 数据清空功能

## 技术栈

- **Electron** - 桌面应用框架
- **Vue 3** - 前端框架
- **Element Plus** - UI 组件库
- **ECharts** - 图表库
- **better-sqlite3** - SQLite 数据库

## 安装运行

### 环境要求
- Node.js >= 16.0.0
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发运行
```bash
npm run dev
# 或
npm start
```

### 打包构建
```bash
npm run build
```

## 数据库

数据存储在用户数据目录下的 SQLite 数据库文件中：
- Windows: `C:\Users\<用户名>\AppData\Roaming\aMoneySystem\amoneysystem.db`

### 默认预置数据

**标签类型：**
1. 消费必要性（单选）
   - 必需品、可选消费、冲动消费、无必要消费

2. 消费分类（二级分类）
   - 日用品：食品饮料、清洁用品、个人护理
   - 家用电器：大家电、小家电、数码产品
   - 水电暖燃物业费：水费、电费、燃气费、物业费、取暖费
   - 交通出行：公共交通、打车、油费、停车费
   - 休闲娱乐：电影演出、旅游度假、运动健身
   - 医疗健康：药品、体检、医疗服务
   - 教育学习：书籍、培训课程、文具

3. 收入分类（单选）
   - 工资、奖金、投资收益、兼职、其他收入

**默认家庭：**
- 默认家庭 - 本人

## 数据备份

应用支持数据导出为 JSON 文件进行备份，重装系统或更换设备时可通过导入功能恢复数据。

## 使用说明

1. **首次使用**：系统会自动创建默认家庭和默认标签配置
2. **添加账单**：点击右下角加号按钮或左侧菜单"新增账单"
3. **管理家庭**：在"家庭管理"页面添加家庭成员
4. **自定义标签**：在"系统管理"页面添加/编辑标签类型和值
